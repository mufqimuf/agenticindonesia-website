## 📋 Overview

agenticindonesia is a website for an Indonesian AI automation team that helps businesses implement practical automation solutions without expensive vendor lock-in.

### What We Offer

- **Custom AI Automation** — Tailored AI workflows for your business needs
- **VPS Setup & Management** — Production-ready server infrastructure
- **Execution Blueprints** — Documented, reusable automation templates

### Our Principles

- **Async-first** — No meeting marathons. Clear communication through docs and threads.
- **Transparent pricing** — No hidden fees. You know exactly what you're paying.
- **Shipped, not stalled** — We measure success by what runs in production.
- **Local context** — We understand Indonesian business culture and market dynamics.

## 🛠 Tech Stack

- **Frontend:** Vanilla HTML, CSS, JavaScript (no frameworks)
- **Fonts:** [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) + [DM Sans](https://fonts.google.com/specimen/DM+Sans) + [DM Mono](https://fonts.google.com/specimen/DM+Mono)
- **Icons:** Inline SVG, Lucide Icons
- **Hosting:** VPS with Caddy reverse proxy
- **DNS:** Cloudflare
